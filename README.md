# 🚀 ResumeMate AI

An AI-powered Resume Builder that helps users create professional, ATS-friendly resumes using Google Gemini AI.

---

## 📌 Features

- 🔐 User Authentication (JWT)
- 🤖 AI Resume Generation using Gemini AI
- ✍️ Create & Edit Resume
- 📊 Resume Match Insights
- 👤 User Profile Management
- 📄 Download Resume
- 📱 Responsive Design

---

## 🛠 Tech Stack

### Frontend

- React.js
- Redux Toolkit
- React Router DOM
- Axios
- CSS
- Vite

### Backend

- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication
- Bcrypt.js

### AI

- Google Gemini API

## ⚙ Installation

### Clone Repository

```bash
git clone https://github.com/YOUR_USERNAME/Resumate-AI.git
```

```bash
cd Resumate-AI
```

---

### Install Backend

```bash
cd backend
npm install
```

---

### Install Frontend

```bash
cd ../frontend
npm install
```

---

## Environment Variables

### Backend (.env)

```env
PORT=5000

MONGO_URI=your_mongodb_uri

JWT_SECRET=your_secret_key

GEMINI_API_KEY=your_gemini_api_key
```

---

## Run Backend

```bash
cd backend
npm run dev
```

---

## Run Frontend

```bash
cd frontend
npm run dev
```
